## Regras de Negócio - Sistema YouLyrics

**RF001:** Os temas (Themes) de uma mesma produção textual devem ser distintos.
**RF002:** Um mesmo Feedback deve possuir critérios distintos.
**RF003:** O intervarlo válido para notas de CriteriaFeedback é de 0 a 10.
**RF004:** Somente o autor de uma produção textual pode exclui-la.
**RF005:** Somente o autor de uma produção textual pode editá-la.
