# Feed
## Textual Production - Post
### Master (no feed)
- CONTENT: 
    - Titulo
    - Nome do Autor (com link para perfil do autor)
    - Conteúdo Parcial (se ultrapassar o tamanho máximo)
- ACTIONS:
    - Ver Perfil do Autor
    - Curtir
    - Comentar
    - Compartilhar
    - Salvar
    - Detalhes
    - Copiar Link
### Detail (foco)
- CONTENT:
    - Titulo
    - Nome do Autor (com link para perfil do autor)
    - Conteúdo (Completo)
    - Comentários
    - Gênero Literário
    - Temas
- ACTIONS: 
    - Ver Perfil do Autor
    - Curtir
    - Comentar
    - Compartilhar
    - Salvar
    - Copiar Link
    - Pesquisa do Gênero Literário
    - Pesquisa do Tema
    - Voltar (Sair do Foco)
